# ShadowFox-Data-Analyst- Beginner Level Project
## Project Overview
This project analyzes buke market data (covering both new and pre-owned listings) using a spreadsheet-based dashboard in Excel.
## Key Features & Structure
-**Bike Prices (Data Sheet):** Raw dataset tracking brands, models, selling prices, years, and ownership history.
-**Dashboard:** Interactive visualizations displaying brand distribution, year-wise sales, ex-showroom pricing and owner types.
## Tools Used
- Microsoft Excel
